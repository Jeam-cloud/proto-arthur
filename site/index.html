Arthur

A personal AI assistant that lives on your computer. No subscription. No account. Your conversations never leave your machine.

Download for Windows
arthur-setup.exe · free & open source · installs Ollama & a local model on first run

💬 Real chat, fully local

Streams answers token by token from a model running on your hardware, picked to match your RAM and GPU.

🧠 Memory you can see

Arthur remembers what matters and brings it up weeks later. Every memory is listed in Settings — edit or delete anything.

🔍 Research & tools

Web research, email & calendar, market data, coding help, even controlling your desktop — each tool scoped, sandboxed, and confirmed with you first.

🛡️ Security that shows its work

Prompt-injection scanning on everything Arthur reads, Docker isolation for risky work, and a visible log of every action blocked or allowed.

🎙️ Voice, offline

Push-to-talk speech recognition runs locally — your voice is never uploaded anywhere.

🔑 Your keys, your choice

Optionally route a single question to GPT or Claude with your own API key — off by default, badge shown when used.

System requirements

OSWindows 10/11, 64-bit
Memory8GB RAM minimum (compact model) · 16GB+ recommended
Disk~1GB app + 2–8GB for your chosen model
GPUOptional — NVIDIA GPU makes replies much faster
OptionalDocker Desktop, for sandboxed research / code / finance tools

The privacy deal, in one line: everything runs locally by default; the only network traffic is the features you explicitly turn on, and Arthur tells you before anything leaves your machine.

Arthur is open source · GitHub · local models won't match frontier cloud models on raw ability — that's the trade, and it's yours to make.
